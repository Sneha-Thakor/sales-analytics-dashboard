# Sales Analytics Dashboard

## Project Overview
An interactive Sales Analytics Dashboard built using Python and Flask to analyze sales data, visualize business performance, and explore key sales insights.

## Features
- Sales data analysis
- Interactive dashboard
- Sales performance visualization
- Data exploration
- Business insights

## Technologies Used
- Python
- Flask
- Pandas
- Matplotlib
- HTML
- CSS

## Project Structure
- app.py – Flask web application
- analysis.py – Sales data analysis
- data/ – Dataset
- static/ – Static assets
- templates/ – HTML templates
- requirements.txt – Dependencies

## How to Run

1. Clone the repository.

2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open in browser
